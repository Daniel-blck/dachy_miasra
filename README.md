# Dachy Miasta

Локальный прототип для планирования установки солнечных панелей на крышах Кракова: карта, выбор объектов под бюджет, сравнение стратегий и экспорт. Интерфейс доступен на русском и польском.

## Запуск

Нужен Node.js 22 или новее; установки npm-зависимостей нет.

```sh
cd dachy-miasto
npm run dev
```

Откройте http://127.0.0.1:4173/. В Windows также можно запустить `START_DACHY.cmd` из корня проекта.

## Проверка и сборка

```sh
cd dachy-miasto
npm test
npm run build
```

`dist/` и `.preview/` создаются локально и не хранятся в Git. Исходный исследовательский пакет `krakow-all-in-one.html` сохранён для воспроизводимого извлечения пилотного набора; команда извлечения — `npm run extract` из папки приложения.

## Отправка на GitHub

Для входа Git в GitHub откройте `scripts/connect-github.cmd` из Проводника Windows. Файл использует установленный Git Credential Manager и вход по одноразовому коду через браузер; пароль или токен в проект не записывается. Авторизация Git в Windows и подключение GitHub к приложению Codex выполняются отдельно.

Для существующего пустого репозитория запустите в обычном PowerShell от своего пользователя:

```powershell
./scripts/push-github.ps1 -RepositoryUrl https://github.com/OWNER/REPOSITORY.git
```

Скрипт создаёт коммит и отправляет текущую ветку через стандартную авторизацию Git. Он не создаёт удалённый репозиторий, не заменяет другой `origin` и не применяет принудительную отправку. Если политика PowerShell запрещает запуск скрипта, те же команды Git можно выполнить вручную: `git add .`, `git commit -m "Add Dachy Miasta"`, `git remote add origin URL`, `git push -u origin main`.

## Данные и ограничения

Пилот содержит 927 крыш. Исходные характеристики извлечены из исследовательского пакета, геометрия получена из MSIP. Мощность, выработка и стоимость — сценарные расчёты. Принадлежность зданий, охранный статус и наличие PV пока не подтверждены.

Источники данных и библиотека Leaflet сохраняют собственные условия использования; перечень источников и ограничения приведены в документации приложения. Общая лицензия на исходный исследовательский пакет и данные этим репозиторием не устанавливается.
