# Dachy Miasta

Прототип на открытых данных Кракова: выбрать крыши под бюджет, объяснить каждое число и сравнить эскизы установки по сезонам, наклону и направлению. Интерфейс RU/PL; язык по умолчанию — польский.

Версия **0.7** сосредоточена на работе с данными. Из приложения удалены мониторинг, USB, прошивки и практический стенд. Вместо них — объёмный эскиз на контуре MSIP и климатическая симуляция на **8 760 часах PVGIS TMY** для Кракова. Покупка и подключение оборудования не входят в проект.

## Запуск

Нужен Node.js 22 или новее. Устанавливать npm-зависимости не требуется.

```sh
cd dachy-miasto
npm run dev
```

Открыть **http://127.0.0.1:4173/**. В Windows можно запустить `START_DACHY.cmd`.

## Пользовательский сценарий

1. В **«Плане»** задать бюджет и фильтры. Карта и список показывают предложенный набор крыш.
2. Выбрать здание и нажать **«Разместить панели на этой крыше»**.
3. В **«Симуляции»** менять наклон и направление модулей; вращать ракурс независимо от установки.
4. Сравнить зиму/лето, более солнечный/пасмурный профиль дня, месяцы и типичный год. Таблица сравнивает варианты одной мощности 1 кВтп.
5. Сохранить эскиз и источники в JSON, профиль дня в CSV или отчёт через печать.

Раздел **«Как читать»** и кнопки **`?`** объясняют значения, источники, формулы и допущения.

## Что подтверждено данными

- 927 объектов пилота извлечены из сохранённого исследовательского HTML.
- Площади и излучение сверены с сохранённым MSIP; контуры зданий, адресные кандидаты, собственность участков и охранные сигналы хранятся локально.
- Климат: PVGIS 5.3, SARAH3/ERA5, период 2005–2023, типичный год для центра Кракова. Приложение работает с локальным снимком, без сетевого запроса погоды при каждом клике.

Плоская крыша, высота 6 м, типовой модуль и отступы — допущения эскиза. Форма скатов, препятствия, несущая способность и межрядные тени не определены. Климатический сценарий не является прогнозом погоды или строительным проектом.

## Проверки

```sh
cd dachy-miasto
npm test
npm run audit:data
npm run build
```

`dist/` и `.preview/` — локальные результаты сборки и проверки, не хранятся в Git. Обновление климата: `npm run climate`. Для повторения из сохранённого ответа: `node scripts/fetch-climate.mjs --from path/to/tmy.json`. Все источники сохраняют собственные условия использования.
