# Мониторинг исключён из версии 0.7

Проект сосредоточен на открытых данных, выборе крыш и [климатической симуляции](SIMULATION.md). Экран мониторинга, импорт измерений, Web Serial и прошивки удалены из текущего приложения. История прежнего прототипа сохранена в Git.

Для актуального сценария начните с [руководства проекта](README.md): контур MSIP → эскиз модулей → климат PVGIS → сравнение сезонов и ориентаций → понятный план.
