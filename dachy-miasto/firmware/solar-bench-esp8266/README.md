# D1 Mini ESP8266 + INA219 + OLED SSD1306

Этот вариант подготовлен под имеющийся у пользователя D1 Mini ESP8266 и OLED I2C 128 × 64. Nano/Uno покупать не требуется. Прошивка ещё не скомпилирована инструментарием ESP8266 и не проверена на оборудовании: в текущей среде Arduino CLI и набор плат отсутствуют.

Контроллер получает питание и передаёт данные по USB. OLED показывает напряжение, ток, мощность и энергию с момента перезапуска. Wi-Fi для этого опыта отключён; паролей и серверов в скетче нет. OLED необязателен: если он не найден, передача измерений INA219 по USB продолжает работать.

## Что уже есть и что ещё нужно

У пользователя есть D1 Mini ESP8266, breadboard, Dupont Male–Male, один OLED SSD1306 0.96 I2C 128 × 64 и резисторы неизвестных номиналов/мощности. Для полного опыта ещё нужны солнечная панель и INA219, а также USB-кабель с передачей данных. Подходящую нагрузку выбираем после уточнения резисторов. Если штыревые разъёмы платы или модулей не припаяны, понадобится пайка. На breadboard используются только модули с соответствующими разъёмами.

## I2C: общая шина двух модулей

| D1 Mini | INA219 | OLED SSD1306 I2C |
| --- | --- | --- |
| `3V3` | Питание логики `VCC` / `VDD` (на некоторых модулях `VIN`) | `VCC`, если конкретный модуль поддерживает 3,3 В |
| `G` / `GND` | `GND` | `GND` |
| `D2` / `GPIO4` | `SDA` | `SDA` |
| `D1` / `GPIO5` | `SCL` | `SCL` |

INA219 обычно имеет адрес `0x40`; для этого адреса подготовлен скетч. OLED проверяется по адресам `0x3C` и `0x3D`. Разные адреса позволяют обоим модулям работать на общих SDA/SCL. Сверяйте подписи выводов: порядок GND/VCC у разных OLED бывает разным.

**Выводы ESP8266 работают с логикой 3,3 В.** Питание модулей и подтяжки SDA/SCL должны соответствовать 3,3 В. Название SSD1306 само по себе не подтверждает диапазон питания конкретной платы OLED: его нужно проверить по маркировке/документации. Если модулю требуется 5 В, эту схему нельзя использовать без отдельной проверки согласования уровней. Измеряемое напряжение панели поступает только на измерительные `VIN+`/`VIN−` INA219; эти выводы отличаются от питания логики модуля.

## Силовая цепь панели

```text
Панель + ── INA219 VIN+ ── внутренний шунт ── VIN− ── резистор нагрузки ── Панель −
                                                                               │
                                                                Общий GND ─────┘
```

Общий GND объединяет минус панели, минус нагрузки, GND измерителя и GND D1 Mini. Панель не подключается к `3V3`, `5V`, `A0` или цифровым выводам D1 Mini. Контроллер и OLED питаются от USB отдельно от солнечной нагрузки. Измеряется полезная DC-мощность на нагрузке после шунта, а не питание контроллера.

Подготовленная калибровка INA219 рассчитана на шунт **0,1 Ом / R100**. Для другого шунта требуется другая калибровка. Мощность резистора нагрузки рассчитывается как `P = U² / R` с учётом максимального напряжения панели. Например, при 6 В на 12 Ом получается 3 Вт: один обычный резистор 0,25 Вт для такой нагрузки не подходит. Номиналы имеющихся резисторов пока неизвестны, поэтому конкретное соединение нагрузки ещё не выбрано.

## Загрузка

1. В Arduino IDE установить пакет плат **esp8266 by ESP8266 Community** по [официальной инструкции](https://arduino-esp8266.readthedocs.io/en/latest/installing.html).
2. Выбрать плату **LOLIN(WEMOS) D1 R2 & mini** и COM-порт своей платы.
3. Установить через Library Manager библиотеки **Adafruit INA219**, **Adafruit SSD1306** и **Adafruit GFX Library**, включая предложенные зависимости BusIO.
4. Открыть `solar-bench-esp8266.ino`, проверить разводку и скомпилировать/загрузить.
5. Закрыть Serial Monitor, открыть приложение → «Мониторинг» → «Подключить USB-стенд» в настольном Chrome/Edge. Выбрать COM-порт. Скорость — 115200 бод.

Скетч передаёт тот же формат, который уже принимает приложение, поэтому изменения браузерного протокола не нужны:

```json
{"voltageV":5.2,"currentA":0.08}
```

Плата ESP8266 может вывести загрузочный текст при сбросе. Это не измерения; приложение пропустит посторонние строки и начнёт график по корректным JSON-строкам. Сообщение ошибки INA219 не заменяется нулевой генерацией. При отрицательном токе проверьте направление цепи и нулевой сдвиг; знак программно не переворачивается.

OLED считает энергию только между соседними корректными измерениями с промежутком до 3 секунд. Счётчик сбрасывается при перезапуске и не записывается во flash. В браузере действует собственная интеграция по времени приёма и свой предел пропусков, поэтому показания двух счётчиков могут немного различаться. Измерения под светом в помещении нужно проверить на собранном стенде.

Основания: [выводы D1 Mini](https://www.wemos.cc/en/latest/d1/d1_mini_3.1.0.html), [питание и адрес INA219](https://learn.adafruit.com/adafruit-ina219-current-sensor-breakout/pinouts), [библиотека SSD1306 и поддержка ESP8266](https://github.com/adafruit/Adafruit_SSD1306).
